# Native ChatGPT Headstrap Benchmark

## Purpose

Before building the custom Urzasight app, test the product idea with the least custom software possible: native ChatGPT on a phone mounted near eye level, plus AirPods for audio.

This benchmark should answer whether the experience is useful enough to justify the USB camera and API prototype.

## Setup

- Phone with native ChatGPT installed.
- Head strap, chest mount, or glasses-style phone mount.
- AirPods paired to the phone.
- Physical manga volume or printed manga page.
- Indoor reading light similar to normal use.

## Test Script

1. Mount the phone so the camera sees the page.
2. Start a voice/camera ChatGPT session.
3. Read normally for 10 to 20 minutes.
4. Ask for help on several speech bubbles.
5. Note every time you need to adjust the page, head angle, lighting, or prompt.

Example prompts:

- "What does this bubble say?"
- "Give me the reading and natural meaning."
- "Explain the grammar in one sentence."
- "What is the tone of this line?"

## What To Measure

- Time from question to useful answer.
- Whether the model sees the correct bubble.
- Whether the answer is short enough to keep reading.
- Comfort of the mount.
- AirPods microphone reliability.
- How often lighting, focus, or framing fails.

## Pass Criteria

Continue toward the USB camera prototype if:

- The camera can usually see the intended text.
- Spoken answers are helpful while reading.
- The physical setup is tolerable for at least 20 minutes.
- The main problems look like hardware/app-control issues rather than concept issues.
